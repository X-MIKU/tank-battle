# 坦克大战 · Tank Battle

一个用纯 HTML5 Canvas 实现的经典《坦克大战》单人游戏，零依赖，双击 `index.html` 即可在浏览器中游玩。

## 玩法

- **目标**：守住画面下方的基地（红旗），并消灭每一关的所有敌方坦克。
- **移动**：`W A S D` 或方向键
- **开火**：`空格` 或 `J`
- **暂停 / 继续**：`P`
- **音效开关**：`M`
- **开始 / 重新开始**：`Enter`

## 特性

- 经典砖墙（可摧毁）、钢墙（不可摧毁）、水域（阻挡坦克、子弹可穿过）、草丛（隐藏坦克）
- 4 种敌方坦克：普通、快速、装甲、以及击杀后掉落道具的闪烁坦克
- 道具：护盾、生命 +1、连射
- 生命、积分、关卡系统，逐关提升难度
- 合成音效（Web Audio），可静音

## 运行

直接用浏览器打开 `index.html`，无需服务器或构建步骤：

```bash
# Windows
start index.html
```

或部署到 GitHub Pages 等任意静态托管。
